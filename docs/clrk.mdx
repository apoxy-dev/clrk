## clrk dev

Run controller-manager and worker locally in Docker

### Synopsis

Starts a controller-manager container with an embedded apiserver and N worker containers on a shared docker network.

```
clrk dev [flags]
```

### Options

```
  -f, --apply stringArray         YAML file or directory of CRDs to server-side apply once the apiserver is ready (repeatable).
      --controller-image string   Controller-manager image ref. (default "us-west1-docker.pkg.dev/apoxy-dev/public/clrk-controller-manager:latest")
      --data-dir string           Host path for ~/.clrk state (defaults to --clrk-dir).
  -h, --help                      help for dev
      --k3s-image string          k3s image ref. (default "rancher/k3s:v1.34.1-k3s1")
      --pull string               Forwarded to 'docker run --pull' for every clrk-managed container. Accepted: "always", "missing" (docker default), "never". Use "always" to force a re-pull when a SHA-tagged image was retagged out-of-band.
  -R, --recursive                 Recurse into subdirectories when --apply targets a directory.
      --reload-tar stringArray    Watch a bazel-built OCI tarball and reload the matching component on every mtime change (repeatable). Format: COMPONENT=PATH where COMPONENT is 'worker[-N]' or 'controller-manager'. Example: --reload-tar=worker=bazel-bin/clrk/worker_oci_tarball/tarball.tar
      --secret stringArray        Materialize an Opaque Secret from the host env before --apply runs (repeatable). Format: NAME=ENVVAR[:KEY]. KEY defaults to ENVVAR lowercased with '_' → '-' (e.g. ANTHROPIC_API_KEY → anthropic-api-key). Multiple --secret flags sharing a NAME merge into one Secret with multiple keys.
      --skip-preflight            Skip the host-readiness checks (docker daemon, /dev/net/tun, IPv6, image-pullable). Use only when the checks are wrong about your environment.
      --tui                       Render the dev TUI (auto-disabled when stdout isn't a TTY). (default true)
      --watch                     Rebuild and hot-reload binaries on source changes (experimental).
      --worker-image string       Worker image ref. (default "us-west1-docker.pkg.dev/apoxy-dev/public/clrk-worker:latest")
      --workers int               Number of worker replicas. (default 1)
```

### Options inherited from parent commands

```

      --log-level string   Log level (debug, info, warn, error). (default "info")
```

## clrk secret set

Apply an Opaque Secret with one or more keys

### Synopsis

Server-side-applies an Opaque Secret with the supplied data keys. Sources are repeatable and merge into the same Secret with field manager `clrk-dev`. --local targets ~/.clrk/kubeconfig.host (the running clrk dev session); otherwise resolution falls back to --kubeconfig and $KUBECONFIG.

```
clrk secret set NAME [flags]
```

### Options

```
      --from-env stringArray       key=ENVVAR — read the value of the named environment variable into the Secret under data[key]. Repeatable.
      --from-file stringArray      key=PATH — file contents into data[key]. Repeatable.
      --from-literal stringArray   key=VALUE — verbatim string into data[key]. Repeatable.
  -h, --help                       help for set
      --kubeconfig string          Explicit kubeconfig path (takes precedence over --local and $KUBECONFIG).
      --local                      Target the kubeconfig of the running 'clrk dev' session (~/.clrk/kubeconfig.host).
  -n, --namespace string           Target namespace (default: "default").
```

### Options inherited from parent commands

```
      --clrk-dir string    State directory for clrk. (default "$HOME/.clrk")
      --log-level string   Log level (debug, info, warn, error). (default "info")
```
